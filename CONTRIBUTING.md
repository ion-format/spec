# Contributing to ION Format

Thank you for your interest in contributing to ION Format!

## Ways to Contribute

### 1. Propose a new tag
Open a Discussion with prefix `[NEW TAG]`

### 2. Propose a new record type
Open a Discussion with prefix `[NEW TYPE]`

### 3. Report a spec issue
Open an Issue

### 4. Improve documentation
Open a Pull Request

## Review Process

1. Open Discussion or Issue
2. Community feedback (minimum 2 weeks)
3. Core team review
4. Merge into next release

## Code of Conduct

Be respectful. We're all here to make hockey better.
